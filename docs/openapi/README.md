# OpenAPI specs

These files are generated from the `proto/pathfinder` definitions via `make generate-openapi` (uses `proto/buf.gen.openapi.v1.yaml` and `proto/buf.gen.openapi.v2beta.yaml` with the [`protoc-gen-connect-openapi`](https://github.com/sudorandom/protoc-gen-connect-openapi) plugin). Do not hand-edit them — change the source `.proto` files and regenerate instead.

They're committed here so the dedicated docs website's sync script can fetch them from this repo's `main` branch.
